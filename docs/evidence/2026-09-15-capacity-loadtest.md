# 百群容量压测与优化建议（第②③步）

日期：2026-09-15。执行：`scripts/capacity_loadtest.py`（本报告配套工具，进仓库、可复现）。
前置：基线见 [capacity-baseline](2026-09-15-capacity-baseline.md)（13 群/日均 ~800 条/积压 0；AI 24h p95 5.3s）。

## 1. 方法（隔离，零生产风险）

- **隔离库**：`data/loadtest/loadtest.db`（启动前强校验路径含 `loadtest`，绝不用生产库）；SHADOW、真实动作关闭、通知关闭。
- **Mock AI**：本机 OpenAI-compatible 服务（:8788），按生产延迟分布模拟（90% ≈1.6s / 10% ≈5.3s），无真实外呼与费用。
- **真实全链路**：durable inbox 入库 → 3 worker 认领 → 解析 → 规则 → AI → 落库；**保留生产限流参数**（`AI_PER_MINUTE_LIMIT=90`、`AI_DAILY_CALL_LIMIT=3000`）以暴露边界。
- 中性文本、AI 一律返回正常：只测吞吐/积压/延迟，不压违规与案件写入分支。

## 2. 两轮负载与结果

**轮次 A（8 种文本，缓存有效，贴近"重复广告模板"场景）**：日常 0.25 条/秒 ×3min + 峰值 2.0 条/秒（=120 条/分钟）×8min。

| 指标 | 结果 |
| --- | --- |
| 注入/处理 | 1005 / 1005（100%） |
| 积压峰值 | 49（峰值段初期），**排空 5 秒** |
| AI 限流降级 | 28 次（2.8%） |
| 端到端延迟 | **p50 2.7s / p80 7.1s / p95 21.2s** |
| DB 增长 | 3.4 MB / 1005 条 |

**轮次 B（文本唯一化，缓存失效，贴近"真实多样文本"）**：峰值 2.0 条/秒 ×2.5min。

| 指标 | 结果 |
| --- | --- |
| 注入/处理 | 300 / 300（100%） |
| 积压峰值 | 23（前 45 秒持续冲高后回落），**排空 5 秒** |
| AI 限流降级 | **36 次（12%）** |
| 端到端延迟 | p50 4.1s / p80 9.1s / p95 13.5s |

## 3. 百群容量结论

- **单实例处理上限（真实条件：多样文本 + 真实 AI 延迟 + 现行限流）≈ 90–100 条/分钟**：由 `AI_PER_MINUTE_LIMIT=90` 与 3 worker × 1.6–5.3s AI 延迟共同约束（纯 AI 并发能力 ≈ 100 条/分钟；限流 90 条/分钟为硬顶）。
- **百群日常（≈14 条/分钟）**：富余 6–7 倍，**当前配置充分**。
- **百群极端峰值（120–140 条/分钟）**：**超出上限**，表现为：峰值期约 25–30% 调用被限流 → 降级为 `record_only` 转人工（**不处罚、不漏放**，降级有告警与转人工兜底）、积压冲高 20–50 条后自愈（排空 ≤5 秒，系统稳定不崩）。
- 缓存对峰值吸收显著（相同模板文本时限流率仅 2.8% vs 12%）；重复广告为主的群实际压力低于轮次 B。

## 4. 优化建议（按优先级）

| # | 项 | 建议 | 依据 |
| --- | --- | --- | --- |
| 1 | **每日调用上限** | `AI_DAILY_CALL_LIMIT` 3000 → **25000+**（必须） | 百群日量 ≈2 万条 × 1.16 次调用 ≈2.3 万；现行 3000 会在百群下**午前即耗尽 → 全天降级** |
| 2 | **每分钟限流** | `AI_PER_MINUTE_LIMIT` 90 → **150–200**（先与服务商确认限速） | 极端峰值需 120–140 次/分钟；现行 90 为吞吐硬顶 |
| 3 | **worker 并发** | `_WORKER_CONCURRENCY` 3 → 6（代码常量） | AI 等待为 IO-bound；压测中 SQLite 无锁竞争问题，提升后吞吐理论翻倍 |
| 4 | 缓存 | 保持重复模板的高命中（主/补测对比显著） | 轮次 A 限流率 2.8% vs B 12% |
| 5 | 费用台账 | `cost_cents` 当前全 0，接入计费字段后估算真实费用 | 基线/压测均无计价 |
| 6 | 降级安全 | 已验证：限流 → `record_only` 转人工 + 告警，不处罚不漏放 | 轮次 B 12% 降级均安全落地 |

## 5. 限制声明

- Mock AI 未模拟真实服务商的网络抖动、并发上限与计费；真实服务商限速可能低于本地结论所需值。
- 未压图片/视频消息（视觉二审路径）与违规/案件写入分支（真实占比低但存在）。
- 单实例验证；多实例、官方通道、100 个真实群的端到端仍需在获群后实测。
