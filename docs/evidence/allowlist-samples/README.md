## 为什么放在这里就能长期保存

- 本目录在**仓库内**，运行期清理**只处理 `data/` 下的受管副本**——
  `app/ops/cleanup.py` 的 `_ManagedCopy("t002_media", 15, …)` 等 TTL 规则挂在 `_managed_copy_root()` 下，
  **不会读取或删除仓库文件**；早期样本被删正是因为当时只存在 `data/t002_media`。
- 同时这些样本随 **git 版本管理**：有提交历史、可追溯、不会因本机清理或换机器而丢失。
