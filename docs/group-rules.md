- **二维码/小程序码不能一刀切**：群允许「万能校园墙」海报中的小程序码，但违规样本中同样存在小程序分享卡片码。二维码/卡片检测必须结合**白名单匹配**（感知哈希比对允许海报、或卡片 source 名称白名单）判定。

## 色情/暴力类样本获取方式说明

不采用"全网搜索下载色情/暴力图片入库"的方式：该类素材存在法律与内容安全风险（尤其涉未成年人素材的边界），且仓库保存此类原始图片违反项目隐私与安全原则。替代方案（T-203 供应商评测时一并决策）：

1. **识别能力优先交给专业内容安全服务**（如腾讯云图片内容安全等，需按 D-005 以脱敏样本评测后选定），本项目不自建该类图库；
2. 本项目自建样本限于**文字边界定义**（黑名单词、变体写法）与**合规渠道的公开测试素材**；
3. 验收口径中该类别的"正例样本"改由内容安全服务商的评测集承担，本项目保留边界定义与降级策略。此调整属于验收指标实现方式变化，需负责人确认后记入 `DECISIONS.md`。
