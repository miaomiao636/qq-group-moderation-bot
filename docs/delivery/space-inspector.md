# QQ 空间限制巡检操作手册

配套入口：[交付说明](../../DELIVERY.md)；主服务配置见 [群管理手册](group-management.md)，故障、数据与验收见 [维护清单](acceptance-maintenance.md)。本工具正常使用不连接手机、不依赖 Codex，也不需要打开群管理后台网页。

## 部署人员：首次配置

1. 先完成主项目的源码、Python/uv、`ONEBOT_SELF_ID` 配置，并确保同机 NapCat 已登录对应 QQ。准备 Microsoft Edge 与含 Tk 的 Python；本版使用 Edge，无须另装 Chromium 来替代。
2. 在该账号的 NapCat 网络配置中保留主服务的 WebSocket 客户端，并配置**恰好一个启用的 HTTP 服务端**。监听地址使用明确的 `127.0.0.1` / `localhost` / 回环 IPv6，端口不与主服务或其他程序冲突；不要开放为 `0.0.0.0` 或公网地址。
3. 巡检读取 NapCat 的 `onebot11_<机器人QQ>.json`，默认目录为 `D:\QQ\config`，从中取得 HTTP 地址和令牌。这里的 QQ 必须与项目 `ONEBOT_SELF_ID` 及 NapCat 当前身份一致。
4. 若配置目录不同，设置启动进程的 `QQ_SPACE_NAPCAT_CONFIG_DIR` 环境变量。**只把它写入项目 `.env` 不会生效**。使用 Windows 用户环境变量时，须重新登录 Windows，使桌面快捷方式继承新环境；首次可先在当前 PowerShell 设置并启动验证。不要把令牌填到命令行或发送给维护人员。
5. 在长期保留的项目目录执行安装，安装脚本不会安装 Python、uv、Edge 或 NapCat：

```powershell
Set-Location '<项目目录>'
.\scripts\install-space-inspector.ps1 -PythonPath '<带Tk的Python完整路径>'
```

脚本创建桌面“QQ空间限制巡检”快捷方式，将独立运行环境装到当前 Windows 用户的 `%LOCALAPPDATA%\QQSpaceInspector\runtime`。源码仍在项目目录，安装后不能删除或移动源码。此脚本不迁移主数据库、不启用群动作，也不重启主服务。

非默认 NapCat 目录的临时验证启动方式：

```powershell
Set-Location '<项目目录>'
$env:QQ_SPACE_NAPCAT_CONFIG_DIR = '<NapCat配置目录>'
& "$env:LOCALAPPDATA\QQSpaceInspector\runtime\Scripts\pythonw.exe" -m app.space_inspector
```

以上变量只对当前终端及其子进程有效，不能当作以后桌面启动已配置完成。主服务和巡检共用项目身份配置，换机器人账号应由维护人员安排，不在正在扫描时修改。

## 操作人员：一次检查

1. 打开桌面工具，点“刷新群列表”，确认“群目录机器人账号”正确。
2. 点“打开空间登录”，在专用浏览器本人登录 QQ 空间，再点“确认已登录”。不要在聊天、工单或截图中发送密码、Cookie 或二维码。
3. 搜索群名或群号并选择群，点“开始检查所选群”。群列表取自 NapCat 账号，不取自空间访问账号，也不受主服务“审核/动作已启用群”筛选。
4. 等待检查。需要停止时点“暂停”；平台拦截或登录失效会保存已有结果并停止，按提示处理后才能继续。
5. 点“导出结果”，再点“打开本次结果”，按群名和群号查看表格。每次导出是新快照，未完成任务也能导出。

### 窗口各部分

| 控件/显示 | 作用 |
| --- | --- |
| 查找群 / 选择筛选结果 / 清空选择 | 筛选和选择新建任务的群；不会改变已载入任务 |
| 开始检查所选群 | 获取当时成员快照并创建新任务 |
| 载入已有任务 | 从列表按群名、群号、创建时间选择保存任务，不会自动扫描 |
| 继续检查 | 继续当前任务未完成的成员，须保持原来源账号和访问账号 |
| 暂停 | 保存已完成记录并停止后续访问；当前页面结束可能需要等待 |
| 留待复查并继续 | 只对已确认身份但格式未知的单个成员页暂缓；不适用于平台拦截或登录问题 |
| 当前任务 | 当前载入任务的群和时间，可能与上方新建选群不同 |
| 续扫数据 / 打开任务数据 | 查看内部任务记录；不是可删除的临时导出文件 |
| 最近导出 / 打开本次结果 | 打开最近生成的实际结果目录 |
| 导出总目录 / 选择导出位置 | 选择可写文件夹并记住；仅影响后续导出，不搬动旧文件 |
| 查看所有导出 | 打开当前导出总目录；改目录前的结果仍在原处 |
| 自动续批 | 达到每批人数后休息，再继续待检队列 |
| 间隔、每批人数、批间休息 | 调节串行访问节奏；不是腾讯允许频率，不能保证免拦截 |
| 复用历史观察 | 在同一访问账号、兼容判据及支持的时间范围内使用已有观察，保留原时间 |
| 轻量加载 | 减少部分图片/字体等资源加载，不等于直接接口批量查询 |

扫描时目录选择及其他冲突操作会禁用。导出位置会持久保存；其他扫描选项当前重开窗口恢复默认，不要误认为全部设置都记住了。

### 怎样理解数量和结果

“成员数”是当前任务中去重后的 QQ 数。同一个人加入多个所选群只检查一次，所以该数字可能小于各群人数相加；导出仍保留该账号属于每个群的关系。“已有观察”包含历史复用，并不等于本次实际访问次数。群成员关系是创建任务时的快照，之后退群或新入群不会自动更新旧任务。

- **观察到限制**：访问时明确出现已识别的 QQ 空间违规限制提示；不直接等于永久失效账号。
- **待确认**：包括普通页面、权限不足、未开通、非好友维护页；没有命中不代表账号正常。
- **未完成**：包括尚未检查、暂缓和访问受阻；不能把它们当作已检查或正常。

历史复用保留原观察时间；关闭复用不会重查已完成的当前任务。需要重新评估当前群成员时，新建任务并按需要关闭复用。

### 导出的文件

每次结果目录按群名、群号、导出时间命名。每群有“全部成员”和“观察到限制”CSV；`report.csv` / `restricted.csv` 是总表，`report.json` 和 `说明.txt` 保留核验信息。出现 `COMPLETE` 表示本次文件导出已完成，**不表示全部成员扫描已完成**；扫描完成情况看表内状态。

CSV 可以交给获准接收的公司人员复核，但不能用于恢复任务续扫。任务恢复与备份必须保存内部任务记录，见 [维护清单](acceptance-maintenance.md)。

## 暂停与常见问题

| 现象 | 处理 |
| --- | --- |
| 群列表无法读取 | 由部署人员检查本机 HTTP 配置、目录路径、账号是否一致、NapCat 是否在线 |
| 提示重新登录 | 在专用浏览器正常登录并重新确认，不使用别人的登录会话 |
| 腾讯安全防护拦截 | 停止重试，待本人确认正常访问恢复后再确认浏览器；不换 IP/账号绕过 |
| 页面格式未知 | 看当前页面并保留具体 QQ 与提示供公司内部复核；允许时可留待复查 |
| AppData 看不到 | Windows 默认隐藏；使用“载入已有任务”“打开任务数据”，不用手动寻找 |
| 自定义导出磁盘不可用 | 连接对应磁盘或重选目录；工具不会悄悄改存到桌面 |
| 新按钮未出现 | 暂停后关闭旧窗口，再从桌面重开；运行窗口不会自动热更新 |

巡检只读目录和空间提示，不控制主服务授权，不向群发送消息，也不踢人。将结果用于处置之前仍需按 [群管理手册](group-management.md#与巡检配合的边界) 人工核实。
