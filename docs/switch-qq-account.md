# 更换 NapCat 登录 QQ 账号操作手册（2026-09-16）

> **最近一次换号实操记录**（含真实遇到的问题与解决方法）：`docs/2026-09-16-account-switch-practice.md`
> ——2026-09-16 完成 <OLD_BOT_QQ> → <BOT_QQ>，完整过程、排错清单、验证数据可作下次参考。

适用范围：本机（Windows 专用机）从当前登录的 QQ 账号切换到另一个 QQ 账号（`.env ONEBOT_SELF_ID` 需同步改为新号）。
**判定规则 / 白名单 / 授权群全部沿用**——所有策略存于数据库与代码，与登录哪个 QQ 无关。

## 0. 结论速览

| 事项 | 要求 |
| --- | --- |
| **系统侧必改** | `.env` 的 `ONEBOT_SELF_ID` 改为新号（动作通道按它绑定校验；**不改则撤回/禁言等动作发不出去**） |
| **NapCat 侧必做** | WebUI 退出旧号 → 登录新号（**需重新扫码**；快速登录凭据作废） |
| **新号必做** | 加入全部 11 个授权群，并在每个群**设为管理员**（否则无法撤回他人消息） |
| **不需要动** | 授权群、白名单、动态规则、豁免策略（办证/卡片/白名单）、动作开关、历史数据、去重键 |
| **建议** | 切换当天可先关真实动作（观察 1–2 天新号稳定后再开——QQ 新设备/新号有风控期） |

## 1. 操作步骤（建议停机窗口 10–15 分钟）

1. **（可选）先拉急停**：后台"立即停止全部外部动作"（或 `.env` `ONEBOT_ACTIONS_ENABLED=false` + 重启）——避免切换期误动作。
2. **NapCat 换号**（WebUI，默认 `http://127.0.0.1:6099`）：
   - 退出当前 QQ 账号；
   - 用**新 QQ** 扫码登录；
   - 确认 OneBot 反向 WS 配置不变（地址 `ws://127.0.0.1:8001/onebot/ws`、Token 不变）。
3. **新 QQ 入群 + 设管理员**：加入全部 11 个授权群（17598122 / 470794920 / 6638171 / 869142826 / 894723164 / 330380007 / 476796763 / 544140282 / 67602330 / 868995385 / 983434859），**每个群都设为群管理员**。
4. **改 `.env`**：`ONEBOT_SELF_ID=<新QQ号>`（其他 OneBot 配置不动；访问 Token 与 QQ 号无关）。
5. **重启两个服务**（QQBotRuntime + QQBotWeb），等 healthz `ok`。
6. 按 §3 验证。

## 2. 判定规则是否沿用？

**完全沿用，无需任何重配**：

| 项 | 存储位置 | 换号影响 |
| --- | --- | --- |
| 本地黑/白名单、严重类别策略、豁免（办证/卡片/白名单） | 代码（`app/moderation/*`） | 无 |
| 动态规则、白名单词 | 数据库（`rule_*` / `allowlist_terms`） | 无 |
| 授权群、群级动作开关 | 数据库（按群号，群号不变） | 无 |
| 真实动作开关 / stage / 急停 | `.env` + 数据库 | 无（保持现状） |
| 历史判定 / 案件 / 违规记录 | 数据库 | 无（全部保留） |
| 消息去重键 | `onebot:{self_id}:{message_id}` | 自动适应新 self_id |

## 3. 验证清单（切换后按序做）

1. `http://127.0.0.1:8001/healthz`：`status=ok`、`onebot.login_state=online`、`connect_count≥1`；
2. 群里发一条普通消息 → 后台"影子判定"出现该条（入站正常）；
3. `/onebot/status`（带 Bearer Token）确认 `self_id` 已为新号；
4. **动作测试**（仅授权群、建议挑最小的群）：发一条会触发撤回的测试内容 → `action_intents` 出现 `SUCCEEDED`；
   若新号未设管理员，撤回会 **FAILED**（记录 + 转人工，不静默）；
5. 观察 24h：留意 QQ 风控（NapCat 日志 / 登录状态）。

## 4. 回退

- 换回旧号：NapCat 登录旧号 + `.env` 改回 `ONEBOT_SELF_ID=<旧号>` + 重启；
- 期间任何异常：拉急停或 `ONEBOT_ACTIONS_ENABLED=false` + 重启。

## 5. 风险提示

- 新 QQ 在陌生设备/陌生群**首日风控概率较高**（发消息/撤回可能受限）——建议先影子观察 1–2 天；
- **新号必须每个群都是管理员**（QQ 权限模型：非管理员不能撤回他人消息）；
- 切换不影响历史数据与判定规则；动作审计的 actor/凭据来自新号，留痕自动反映。
