# 部署配置对照表（复刻"同款运行效果"参考）

> 用途：接收方用**自己的账号 / 自己的群 / 自己的密钥**从零部署后，按本表对齐配置，即可达到
> 与原部署一致的运行效果。
> 原则：**代码自带的行为不用配**（判定政策、动作编排、审计、默认规则种子……随代码一致）；
> 本表只列"需要按环境填写或复刻"的部分。
> ⚠️ 本表**不含任何密钥 / 账号 / 邮箱**；`.env` 的真实值只存在于各自机器上。
> 配套：从零部署步骤见 `README.md` §2；验收清单见 `README.md` §3。

## 一、代码自带（无需配置，装完即一致）

| 类别 | 内容 |
| --- | --- |
| 判定政策 | 办证/学历放行、群主/管理员卡片放行、全局白名单"仅免广告"（`DECISIONS.md` D-031 / D-032 / D-033） |
| 动作编排 | 仅自动撤回、急停、按群动作开关、结果未知不复放、全链路审计；不自动禁言或发送群内警告 |

| AI 提示词规则 | `config/ai_prompt_rules.txt`（随仓库交付） |
| 判定阈值常量 | 动态规则高分门槛 0.90 等（代码内） |

## 四、"效果一样"的额外前提（非配置项）

1. **机器人账号在授权群须为管理员/群主**（否则无法撤回；其余功能不受影响）。
2. **AI 模型可用**（同款或等效）；模型/阈值不同 → 判定分布不同。
3. **群规模量级接近**（大群、消息量大）——阈值与策略按此规模调过。
4. **观察期流程**：先影子观察 → 逐群启用仅撤回（README §4）；不再开放禁言档位。
5. **通知渠道各自配置**（不影响审核与动作效果）。
